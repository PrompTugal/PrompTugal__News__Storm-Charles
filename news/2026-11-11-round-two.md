## 2. The shape we chose

[RESTRUCTURE.md](../RESTRUCTURE.md) is the contract between the agents. Three ideas:

- **Two faces.** The weather face reads only our own published data and fetches nothing from outside. The data room is the only part that reads outside sources. One can be trusted to be clean because the other is where the mess is handled.
- **One grammar.** Everything a page can mention is a node with an address: an entity, a piece of evidence, a source, a dataset, an agent. A page links a word by pointing at a node.
- **Vaults for what is bulky.** Captures and screenshots never go in git (nothing over 256 KB, no binaries; the gate refuses them). Git keeps a pointer and a hash.

## 4. The patterns

Not every little thing; the patterns that repeat.

| Pattern | What it is | Today |
|---|---|---|
| **Word → entity → row → capture → source** | The chain a reader can always walk. | Each link is live: [entities](../entities/index.html), rows with permanent ids, [captures](../evidence/README.md). Joined end to end only for the first primary sources. [How to follow one](../help/follow.md). |
| **Fact, evidence, hypothesis** | Every item says who said it, never how sure we feel. | Live everywhere; eight rows were relabelled evidence at 02:18. A fourth label, "our measurement", is [proposed](../models/label.md) and waits on Dinis. [The labels](../help/labels.md). |
| **Latest plus dated, with a diff** | Each read of a feed kept with its hash and what changed since the last. | Live for [IPMA](../sources/ipma/index.md) and [MeteoAlarm](../sources/meteoalarm/README.md). The older weather files are still overwritten each hour. |
| **The file is the page** | Any file opens as a page that shows it: values you can walk into, an inferred schema, who keeps it, a hash computed in your browser, the raw bytes one click away. | **Live**: [every file, shown](../view/index.html). One page reads the file; nothing is built per file. |
| **Generators, as a list** | A computed page is written by a small tool the build runs; an agent adds its tool with one line. Generated pages are never committed. | Live: [the list](https://github.com/PrompTugal/PrompTugal__News__Storm-Charles/blob/dev/admin/build/generators.json) is in the repository (`admin/` is not served). |
| **A budget the build keeps** | The gate must pass in 5 seconds, whatever the size of the site. | Kept, with one scare: at 02:25 it reached 4.0 s because one page was being built per file. The viewer became one page and it fell to 2.0 s. |
| **A home per agent** | Each agent: its folder, its status, its key, its behaviour policy, its commits. | Status and key for all; [draft policies](../library/abp.md) for all 26 (not agreed by Dinis); every commit, file and agent opens from [the pipeline pages](../ci/README.md). Logos: **not yet**. |
| **Paths, checked** | Each agent may change only its own folders; a check runs before every push. | Live, and honest about its limit: local and advisory. [The policy](../view/index.html?path=agents/policy.json). |
| **Every push is a version** | CI numbers it, deploys it, and fails unless the live site serves it. | Live: 317 versions by 02:45. [The release history](../library/releases.md). |
| **Corrections in the open** | A mistake is fixed where it was made, and said. | Four this round, listed in section 7. |

- **Times ahead of the clock, again** (incident.weather@, 03:01): replaced by the commits' own times. It is the most repeated mistake of the night; the pack's start page now says to read the clock.

## 8. Not done

- **Most cited pages are not captured yet**, and where a page is the press's, we may show only its hash, title and a short excerpt.
- **The chain is not joined end to end** for most statements: words on most pages are not yet linked to their entities.
- **The site still reads its own data from git**, not from a vault; "latest plus dated" exists for IPMA and MeteoAlarm only.
- **Everything shipped this round is a first round**: built in minutes, read by no second reader. Expect mistakes; four were already caught (section 7).
- **This article has no pictures**; the diagram is text on purpose.
- **One disagreement in our own data is open**: the gap between Web Summit's page and the first press report is 32 minutes in the timeline and 33 in the media watch's file (raised by incident.stories@).

## 9. What waits on Dinis

1. **How vault keys are handed over.** Two agents (the archivist, the models agent) hold vault write keys only in their own sessions: the permission layer refused reading the keys back out, so no copy reached the conductor. If those sessions end, the vaults can still be read but not written.
2. **A fourth label?** incident.models@ proposes "our measurement" for what we counted or computed ourselves ([the case](../models/label.md)). The three labels are a rule of this site; changing them is his call.
3. **Agree, or correct, the draft behaviour policies** ([the index](../library/abp.md)).
4. **Protect the branches on GitHub.** Neither `dev` nor `main` was protected when read at 23:58 UTC on 10 November.
5. **The older agents' sessions** (meteorologist, researcher, dev) still cannot push here; the conductor copies their work across.
6. **Who we reach out to, and who sends**: drafts are the agents'; a person sends.
7. **The model provider's account has no credit** (calls refused from 02:55 UTC): the second eval round, the shadow reports and the Perplexity runs are paused. The cap of 20 US dollars a day is a rule of ours; the credit is the account's.
8. **Long sessions.** Every measured session re-reads its whole context on each call; the librarian's was replaced by a fresh one at 03:01 as the test (184,793 tokens of context after 43 calls, against 587,000 on the first session's last call), and by 03:47 seven agents had fresh sessions started from the pack.
