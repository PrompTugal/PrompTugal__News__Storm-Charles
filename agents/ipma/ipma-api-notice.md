**Why this draft exists.** IPMA's API page asks its users to write: "O IPMA solicita ainda que seja enviado um email [...] a informar da sua utilização deste serviço e do seu propósito para efeitos de estatística e melhoria do serviço." ([api.ipma.pt](https://api.ipma.pt/), section "sobre", read 11 November 2026, 02:12 UTC). The address is on that page; it is not repeated here.

**Two questions it could also carry**, both open in [sources/ipma/licence.md](../../sources/ipma/licence.md): the logo (IPMA's terms say its logo should accompany its information on web pages; this site shows no images and writes "Source: IPMA" with a link beside every figure), and reshaping (the terms speak of copying and using; this site also draws and tabulates, with everything computed marked as ours).

## The draft (Portuguese)

Assunto: Utilização da API de dados abertos do IPMA: storm-charles.promptugal.news

Exmos. Senhores,

Conforme solicitado na página da API do IPMA, informamos que o sítio https://storm-charles.promptugal.news utiliza os dados abertos disponibilizados em api.ipma.pt/open-data.

Finalidade: um registo público e não comercial da depressão Charles (novembro de 2026), que reúne decisões, avisos e observações de fontes públicas, cada uma com a sua fonte e a hora de leitura. Não é um serviço de avisos: todas as páginas remetem para o IPMA e para a ANEPC.

Como utilizamos a API: leitura apenas, cerca de uma vez por hora, um pedido a cada três segundos (cerca de 63 pedidos por leitura). Os valores do IPMA são apresentados como sendo do IPMA, com ligação ao ficheiro de origem; o que é calculado por nós está identificado como tal.

Duas questões, se nos puderem esclarecer:

1. As condições de utilização referem o uso do logo-símbolo do IPMA. O nosso sítio não apresenta imagens; identificamos a fonte por extenso ("Fonte: IPMA") junto de cada valor, com ligação. É suficiente?
2. Apresentamos os dados também em tabelas e desenhos próprios (por exemplo, os avisos de cada distrito ao longo do tempo). Esta utilização está dentro das condições?

Ao ler a API com atenção reunimos algumas notas que talvez sejam úteis (por exemplo, o endereço documentado do ficheiro de evapotranspiração devolve 404, e o ficheiro existe com outro nome): https://storm-charles.promptugal.news/sources/ipma/learned.html

Obrigado pelo serviço de dados abertos, que foi essencial.

Com os melhores cumprimentos,
[nome de quem envia]

## The same in English (for the sender)

Subject: Use of IPMA's open data API: storm-charles.promptugal.news

As your API page asks, we are letting you know that https://storm-charles.promptugal.news uses the open data at api.ipma.pt/open-data.

Purpose: a public, non-commercial record of Storm Charles (November 2026), gathering decisions, warnings and observations from public sources, each with its source and the time read. It is not a warning service: every page points to IPMA and ANEPC.

How we use the API: read-only, about once an hour, one request every three seconds (about 63 a read). IPMA's values are shown as IPMA's, with a link to the file they came from; what we compute is marked as ours.

Two questions, if you can help: is naming the source in words beside every figure enough where your terms mention the logo (the site shows no images); and is showing the data in our own tables and drawings within your terms?

Reading the API closely we gathered some notes that may be useful (for example, the documented address of the evapotranspiration file answers 404, and the file exists under another name): https://storm-charles.promptugal.news/sources/ipma/learned.html

Thank you for the open data service, which was essential.
