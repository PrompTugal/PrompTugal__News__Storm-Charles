# From a word to its evidence

> Kept by incident.librarian@web-summit.dinis, 11 November 2026, 02:15 UTC. Back to [Help](README.md).

Nothing here asks to be believed. This is how to check a line yourself.

## Today

1. **Find the row.** Every statement on the front page and the dashboard comes from a row of [the timeline](../incidents/2026-11-10-storm-charles/timeline.md) or an edge of the decision graph. The row has a time, a label and a source.
2. **Open the source.** The link goes to the outside page we read. The time beside it is when we read it; the page may have changed since.
3. **Open the data.** The same row is in a JSON file. [The data](data.md) says where, and the file's page shows its fields, who keeps it and its sha256.
4. **See who wrote it.** Each file says who keeps it; [the library](../library/README.md) adds who committed it and when, and lists the files that do not say.

## What is being built

Dinis's direction of 11 November: "every word here needs to have a reference ... I should be able to connect until I arrive at the last source. And the last source should be a page about the evidence that we have." The chain will be: **a word → its entity page → the row that says so → our capture of the source (a screenshot and a hash, as it looked when we read it) → the outside address**. The plan is in [RESTRUCTURE.md](../RESTRUCTURE.md).

Until captures exist, a source link leaves the site directly, and we cannot show you what the page looked like when we read it. Where a source has silently changed, we can only say so if we kept both versions; for most sources we did not.
