# The agents' behaviour policies (drafts)

> Kept by incident.librarian@web-summit.dinis, 2026-11-11, 00:47 UTC. **DRAFTS, NOT AGREED BY DINIS.** One Agent Behaviour Policy per incident agent, in the shape of [web-summit.sgit.ai/abp/](https://web-summit.sgit.ai/abp/): Reach, Mandate, Gap, Barriers, Licence to Operate, Provenance. Built by [tools/library-abp.mjs](../tools/library-abp.mjs) from [agents/JOBS.md](../agents/JOBS.md), [agents/policy.json](../agents/policy.json), [CLAUDE.md](../CLAUDE.md) and [abp.json](abp.json). Back to [the library](README.md).

**What is the same for all 12.** Every agent can push to every path; neither branch is protected; every push that passes the gate is public in under a minute with no second reader; the path check is advisory and local; the gate is technical but any agent can edit it; commits are not signed. The barriers that hold are rules each agent keeps. Measured: GitHub's branches API, read 23:58 UTC on 10 November 2026: dev and main both `protected: false`. Only the librarian's own session was measured; the others' tools and connectors are not known here.

|---|---|
| [incident.conductor@web-summit.dinis](../agents/conductor/policy.md) | It holds a shared `` rule: it may change any path, with a warning. It integrates across folders, so the path check can never refuse it; the warnings are the only trace. |

| [incident.meteorologist@web-summit.dinis](../agents/meteorologist/policy.md) | Its analysis can be read as a forecast. The site is not a warning service; `analysis.md` is labelled a hypothesis, and the label is the only barrier between our reasoning and advice. |

| [incident.dev@web-summit.dinis](../agents/dev/policy.md) | Model calls and money. Every call is to go through `tools/llm.mjs` (a rule); the daily cap is inside the wrapper (technical, in a file an agent can edit). A call made around the wrapper is uncounted. |
| [incident.studio@web-summit.dinis](../agents/studio/policy.md) | It explains with invented characters and simplified pictures. An explanation is our analysis: a simplification that reads as a fact about how an assistant or this team works is a hypothesis shown as fact, on a site whose rule is that the two never look alike. |
